# -（小説執筆プロジェクト）

このリポジトリは、小説の執筆・管理を行うためのプロジェクトです。

## 概要

原稿の執筆、プロット管理、キャラクター設定などをバージョン管理しながら進めるためのリポジトリです。Git を活用することで、執筆の履歴を残しつつ、安心して推敲・改稿を行うことができます。

## 構成（予定）

```
├── README.md        # プロジェクト説明
├── draft/           # 原稿（本文）
├── plot/            # プロット・あらすじ
├── characters/      # キャラクター設定
├── settings/        # 世界観・舞台設定
└── notes/           # メモ・資料
```

## 使い方

1. `draft/` に章ごとのファイルを作成して執筆を進めます
2. `plot/` にあらすじや構成案をまとめます
3. `characters/` にキャラクターの設定を記録します
4. `settings/` に舞台や世界観の設定を整理します
5. `notes/` にアイデアや参考資料をメモします
